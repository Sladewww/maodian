# 锚点 · 今日专注操作系统

把注意力系在今天最重要的三件事上。单文件、本地优先、打开即用。

## 10 秒上手

1. 用浏览器打开本目录下的 `index.html`（双击即可，或拖进 Chrome / Edge / Safari / Firefox）。
2. 也可在本目录启动本地服务：

```bash
cd /workspace/anchor
python3 -m http.server 8765
```

然后访问 `http://localhost:8765`。

无需账号、无需后端。数据只保存在你的浏览器 `localStorage` 里。

## 它能做什么

| 功能 | 说明 |
|------|------|
| **今日三件事** | 固定三个最重要任务槽；勾选完成有反馈；进度条一眼可见 |
| **收件箱** | 快速记下杂念；完成 / 删除；可拖拽排序 |
| **专注计时** | 番茄钟（默认 25/5，可改预设或自定义）；环形进度；开始 / 暂停 / 重置 / 跳过 |
| **草稿纸** | 自由笔记，输入即自动保存 |
| **今日状态** | 心情/能量芯片 + 一句反思 |
| **命令面板** | `⌘K` / `Ctrl+K` 快速跳转与操作 |
| **本地优先** | 全部存本机；支持导出 / 导入 JSON |
| **日切换** | 按 Asia/Shanghai 日期；跨日后昨日三件事与状态归档到「过往锚点」 |
| **通知** | 可选：计时结束时浏览器通知（需授权） |

## 键盘快捷键

| 快捷键 | 作用 |
|--------|------|
| `⌘K` / `Ctrl+K` | 打开 / 关闭命令面板 |
| `↑` `↓` | 命令面板内移动 |
| `Enter` | 执行选中命令 |
| `Esc` | 关闭面板 / 引导层 |

## 设计说明

- 中文界面，日期按 **Asia/Shanghai** 显示（如「2026年10月8日 · 周四」）
- 深色主题：午夜墨色 + 琥珀暖色；沉静、可截图分享的产品感
- 首次打开有简短欢迎引导

## 文件

- `index.html` — 完整产品（CSS / JS 均内联，可单独拷贝带走）
- `README.md` — 本说明

## 注意

- 核心功能可离线使用；字体通过 Google Fonts CDN 加载，无网时会回退系统字体。
- 清除浏览器站点数据会丢失本地记录；请定期「导出 JSON」备份。
- `file://` 下通知权限在部分浏览器可能受限；若需通知，建议用本地 HTTP 服务打开。
